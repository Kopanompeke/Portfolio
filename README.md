## Features

- **Responsive Design**: Fully responsive layout that works on all device sizes

## Installation

1. Clone the repository or download the ZIP file
2. Extract the files to your desired location
3. Open `index.html` in a web browser

No server or additional dependencies required.

## Usage

### Basic Usage
1. Navigate through sections using the navbar or scrolling
2. Click on social media icons to visit profiles
3. Use the project slider to view different projects
4. Fill out the contact form to send a message

### Interactive Elements
- **Skill Buttons**: Hover and click for animations
- **Project Navigation**: Use arrows or keyboard arrows (← →)
- **Mobile Menu**: Click hamburger icon to toggle

## Customization

### Content Changes
1. **Personal Information**:
   - Update name in `index.html` (Home and About sections)
   - Replace profile image in `images/` folder
   - Update social media links in About section

2. **Projects**:
   - Replace placeholder images in `images/` folder
   - Update project titles in `script.js` (labels array)
   - Add more projects by extending the images array

3. **Skills**:
   - Add/remove skills by editing the buttons in Portfolio section

4. **Contact Information**:
   - Update form fields as needed in Contact section

### Style Changes
1. **Color Scheme**:
   - Primary colors: `#30382F` (dark green), `#FFFBDF` (cream)
   - Edit in `style.css` (search for color variables)

2. **Animations**:
   - Adjust animation durations and effects in `style.css`
   - Add new keyframes for custom animations

3. **Layout**:
   - Modify section padding/margins in responsive breakpoints

## Performance Optimization

### Implemented Optimizations
- Lazy loading for images
- Debounced scroll events
- Efficient CSS selectors
- Minimal DOM manipulations
- Optimized animations using CSS transforms

### Further Optimization Tips
1. Compress images before uploading
2. Consider using a CDN for assets
3. Minify CSS and JavaScript for production
4. Implement service workers for caching
